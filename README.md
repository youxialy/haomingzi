# 实习日报一点通

面向顶岗实习学生的报告生成工具：一次配置岗位，之后**每天 30 秒生成日报**，周报、月报、实习总结从日报**一键自动汇总**。数据只存本地浏览器，无账号、无服务器、无上传。

> 参照《沧州职业技术学院-实习系统-学生操作手册》设计：覆盖学习通实习系统里的 **日报 / 周报 / 月报 / 总结** 四类报告；周报月报按批次时间窗提交、过期可能不能补交的特点用「今日该交」提醒面板应对。

## 快速开始

**本地使用**：直接双击 `index.html` 即可（无需安装任何东西）。

**首次使用（5 分钟）**：
1. 打开页面 → 点横幅「去配置」
2. 选岗位类型（电商客服 / 行政文员 / 销售 / 工厂技术 / 护理 / 幼师 / 餐饮酒店 / 通用）
3. 勾选你**真实**的工作模块（可自定义补充），填实习起止日期和字数要求
4. 回「今日日报」→ 点「✨ 生成日报」→ 复制 → 粘贴到学习通提交

**每天（30 秒）**：生成日报 → 复制 → 学习通「上班打卡」→ 粘贴提交日报。

## 功能一览

| 页签 | 功能 |
|---|---|
| 今日日报 | 按日生成/编辑/保存，特殊事项合并，字数统计与达标提示，「换一版」一键换措辞，一键复制，标记已提交；手动改过内容后重新生成会先确认 |
| 周报月报 | 本周/上周、本月/上月或自定义区间，从日报自动汇总成稿，可编辑/复制/打印；留档记录可随时载入或删除 |
| 实习总结 | 汇总全部日报，生成五章结构总结（概况/主要工作/收获/不足/结语） |
| 日历·待办 | 月历查看提交状态，点日期补写；**批量补写缺失日报**（自动找出漏写的工作日一键补齐）；待办清单（含"学习通上班打卡"快捷项） |
| 素材库 | 按场景分类的写作句式，可一键复制或插入今日日报，支持自建收藏 |
| 设置 | 岗位配置、日报栏目自定义（改名/关闭，适配各校模板）、周报/月报批次截止提醒（首页倒计时）、JSON 导出/导入备份、清空数据 |

## 使用边界（务必阅读）

- 本工具自动**写**报告（汇总、成文、排版），工作模块请如实配置——报告内容真实性由使用者自己负责；
- **不做也不建议使用**自动打卡 / 代签 / 脚本刷课：收集他人账号凭证涉嫌侵犯公民个人信息，脚本绕过平台涉嫌非法获取计算机信息系统数据，均已有追责先例。本工具是纯写作辅助，与平台无任何自动化交互；
- 每天手动打卡 + 工具写报告 = 省时且安全。

## 测试

生成引擎有自动化测试（Node 环境运行，不需要浏览器）：

```bash
node test/harness.js
```

覆盖：连续 14 天生成（字数达标、相邻天模块零重叠、模块周期全覆盖、相似度阈值）、周报/月报/总结聚合正确性、备份导出导入往返一致、少量模块边界情况。

## 部署上线（免费）

**GitHub Pages**：
1. 新建公开仓库，把本目录全部文件推上去
2. 仓库 Settings → Pages → Source 选 main 分支根目录 → Save
3. 几分钟后通过 `https://<用户名>.github.io/<仓库名>/` 访问

**Cloudflare Pages**（国内访问通常更快）：Dashboard → Pages → 直接上传或连接 Git 仓库，无需服务器和备案。

## 传播方案（按优先级）

1. **班级实习群冷启动**：发给同班同学，一句话介绍"配一次岗位，以后日报周报自动写"。同学的真实反馈是第一轮迭代依据；
2. **小红书 / 知乎**：在"实习日报怎么写""实习周报模板""顶岗实习"等话题下发内容（把 guide.html 的指南改写成笔记），工具链接放评论或主页；
3. **SEO 长线**：guide.html 承接"实习日报怎么写 / 周报模板 / 月报模板"等搜索词；部署后到 [Google Search Console](https://search.google.com/search-console) 和[百度站长平台](https://ziyuan.baidu.com)提交 `sitemap.xml`；
4. **每年两批实习季**（春 / 秋）需求自然回潮，老内容持续有效。

```
├── test/harness.js     # 生成引擎自动化测试
├── sitemap.xml / robots.txt
└── README.md
```
